# Blitzkamm Production V1

Modularer Vier-Richtungs-Rig für Blitzkamm. Süd, Ost und Nord sind eigenständig gezeichnet; West wird aus Ost gespiegelt. Alle Beine sind vollständige, nahtlose Teile. Die Nordarme werden im Rig hinter dem Körper gezeichnet, damit ihre Ansätze auf der verdeckten Vorder-/Seitenseite liegen.

Generierung: `npm run assets:storm-preview`

Runtime-Ausgabe: `src/assets/characters/storm-next/`

Isolierter Test: `rooster-preview.html`
