# Rooster Final v1

This directory preserves the generated source artwork for the first shared
final-character approval point. The production, next and gameplay assets are
not modified.

Generated source files:

- `generated/ace-west-tail-fan-v1.png`: new five-feather side fan, based on the
  current Ace side tail.
- `generated/ace-north-tail-fan-v1.png`: new seven-feather rear fan, based on
  the current Ace rear tail.
- `generated/artillery-west-body-v1.png`: coherent west-facing Bummbert body
  module with a curved, load-bearing lower contour.

The normalized runtime-ready derivatives are produced by
`scripts/prepare-final-rooster-parts.py` and live under
`src/assets/characters/final-parts/`. The source PNGs remain unchanged so the
normalization is reproducible and reversible.
