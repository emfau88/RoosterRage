# Bummbert Production V1

Modularer Vier-Richtungs-Rig für Bummbert. Süd, West und Nord sind eigenständig gezeichnet; Ost wird aus West gespiegelt. Alle Beine sind vollständige, nahtlose Teile. Die Nordarme werden im Rig hinter dem Körper gezeichnet, damit ihre Ansätze auf der verdeckten Vorder-/Seitenseite liegen.

Generierung: `npm run assets:artillery-preview`

Runtime-Ausgabe: `src/assets/characters/artillery-next/`

Isolierter Test: `rooster-preview.html`
