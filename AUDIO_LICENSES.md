All external sources used in the production audio set were selected as CC0 in the supplied local source manifest. The generated MP3 files in `src/assets/audio/` are derivatives; the original downloads remain untouched outside this repository. Author names below come from the original filename, embedded metadata, or pack metadata. “Not preserved” means the local download did not retain an author tag.
