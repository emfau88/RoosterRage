ROOSTER RAGE — Kongregate upload

RECOMMENDED:
Upload rooster-rage-kongregate-complete.zip as the WebGL/HTML5 file.
Leave Additional Files empty. The ZIP contains index.html and assets/ at its root.

FALLBACK (if the portal provides separate file fields):
Upload index.html as the WebGL/HTML5 file.
Upload rooster-rage-additional-files.zip as Additional Files.

Do not use rooster-rage-additional-files.zip as the main file: it intentionally has no index.html.

KONGREGATE STATISTICS (create in Manage Statistics; exact case):
Kills: type Max, Display in Leaderboards enabled.
RunsWon: type Add, +1 per victory; optionally enable Display in Leaderboards for a wins ranking.
The client API needs no private API key. Scores submit only on Kongregate.
See docs/KONGREGATE_API_SETUP.md in the source repository for testing steps.
